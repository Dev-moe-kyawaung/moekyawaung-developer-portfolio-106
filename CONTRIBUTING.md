# Contributing

Thank you for your interest in improving this portfolio project.

## Ways to Contribute

- Report bugs
- Suggest UI or UX improvements
- Propose performance enhancements
- Improve accessibility
- Refine documentation
- Submit code improvements

## Before You Start

Please:
- Check existing issues before opening a new one
- Keep proposals focused and specific
- Discuss major changes before starting implementation
