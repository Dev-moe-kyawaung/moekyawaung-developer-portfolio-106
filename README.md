## Overview

This project is a frontend portfolio website designed to showcase:
- Software engineering experience

- Transit-data and GTFS-related projects

- Production-quality personal branding

## Features

- Modern developer portfolio layout
- Responsive interface across desktop, tablet, and mobile
- Fast frontend build setup
- Vercel deployment workflow

- Public GitHub repository with governance and security documentation
